# DJ Mighty — Official Website

A dark, 3D-style personal DJ website for **DJ Mighty** (Dallas–Fort Worth).

> High-Energy Sets for Weddings, Clubs & Private Events — 15+ Years of Experience.

## Tech Stack

- **Next.js 15** (App Router, TypeScript, Turbopack)
- **Tailwind CSS** + shadcn/ui primitives
- **Framer Motion** — scroll reveals & spring animations
- Custom **3D effects**: mouse-parallax hero layers, perspective tilt cards with glare, spinning vinyl, 3D grid floor

## Sections

Hero · Genre marquee · Featured Mixes · About · Services · Rates · Gallery · Testimonials · Booking form

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customizing

All site content (name, tagline, phone, email, genres, events) lives in `lib/site.ts`. Photos are referenced by URL in the same file — swap in your own.
